## 結果與限制

本次修正防止缺乏接觸證據、歷史座標和錯誤分類造成假完成。**開發樣本中的錯誤完成由 7 次降為 0 次，但拒判大幅增加，尚未達到七類皆可可靠辨識的程度。** 不應把排除拒判後的高正確比例當成整體辨識準確率。

## 評估方法

- 使用兩個資料夾各七支 MOV，共 14 支、實際讀取 2689 幀。以檔名「內外夾弓大立腕」為片段標籤，保留片頭、片尾及可能轉場，沒有挑除錯誤幀。
- 檢視各片中間畫面確認動作類型；JPG 為既有 HUD 截圖，僅供參考。部分 MOV 也含播放器控制列，是資料限制。
- 全畫面、不額外縮放、rule／free、窗口 0.5 秒、達標門檻 1.0 秒；時間依各影片 FPS 計算。
- 修改前偵測結果保存於 `scratch/sample_detections.json`；修改前後重播相同座標及 observed/held metadata，隔離偵測器差異。偵測器本次未修改。
- 兩組樣本皆用於開發與檢查，**不是獨立測試集**；不能推論新場景的泛化效果。
- 修改前基準是本次開始時的工作目錄版本，並非 Git HEAD；保留使用者原有未提交修改。

## 已實作的邏輯

1. **共同座標與同一隻手的接觸證據**：跨手重疊改用共同影像座標，投影到被洗手的掌寬軸，不再比較各自手腕歸零後的 X。弓／立使用同一主動手的角度、指節、指尖與聚攏程度。
2. **分類規則**：移除「其他類未成立就算內」的 fallback。外要求伸直、軸向與近掌接觸；腕要求對側腕接觸相對掌心／拇指有距離優勢。弓／立的接觸可獨立成立，再對競爭類降分。
3. **單手與 held**：held 不送入分類當作當前接觸；只有單手時回傳 other。目前沒有能可靠確認包覆接觸的單手時序模型，因此遮擋會嚴重影響召回率。
4. **動態特徵**：新增兩手相對關節影像位移，除以掌長與 dt，單位為掌長／秒。共同平移不當成搓洗，過大位移拒絕計時。舊 160 維 ML 向量保留原速度欄位，未替換既有模型的輸入定義。
5. **進度與辨識分離**：移除完成類懲罰與當前類加權。`raw_scores` 現在是分類器直接輸出，FSM 只負責進度與引導。
6. **顯示與計時分離**：新增 `credit_label`、`evidence_reason`。計時要求 raw 與平滑標籤一致、雙手 observed、非重偵測首幀、最高分 ≥0.45、前兩名差 ≥0.12、相對速度 0.15–8.0。最近 0.5 秒需至少有 0.20 秒支持證據；不回補確認期間的時間，只計當前通過的幀。
7. **避免零碎片段湊完成**：歷史有效秒數保留供分析，完成改用 `contiguous_times`；某類超過 1.5 秒無有效證據，重置未完成段。短遮擋暫停、不收取低品質信用。順序模式取消 85% 提前完成。
8. **抑制瞬間換類**：即使候選分數差很大，也要持續至少 0.06 秒才切換顯示。
9. **可追查輸出**：新增 `src/evaluate_samples.py` 與影片 `--trace` 參數，記錄分類、計時、分數、拒判原因與完成事件。

新門檻是工程初值及開發樣本的檢查結果，尚未經獨立資料校準。softmax 仍只是規則分類分數。ML／hybrid 共用計時修正，但本次影片量化僅針對 rule，沒有重訓 ML 模型或宣稱其準確率改善。

## 為何仍有漏判

- sample_v1 真雙手觀測：84/1494 幀（5.6%）。
- sample_v2 真雙手觀測：550/1195 幀（46.0%）。

第一輪曾採「每次失去支持就清空 0.20 秒確認」的方式，正確有效計時降至零；因此最終版本改為有期限的支持證據視窗。仍只對當前有效幀計時，不對遮擋補時。

sample_v1 大量畫面只偵測到一隻手，現有座標不足以可靠確認另一手的接觸位置。下一階段應改善遮擋觀測、收集接觸與動作轉場標註，再驗證近期可靠雙手證據能否支援短遮擋延續。內／夾仍缺乏足夠區分證據；不應恢復單手自動計時或降低完成門檻來湊 7/7。

## 重現指令

macOS 完整偵測測試需在可建立 MediaPipe OpenGL context 的本機環境執行。

```bash
venv/bin/python -m pytest -q

venv/bin/python src/evaluate_samples.py --cache scratch/sample_detections.json --output docs/evaluation/samples_after

# 指定不存在的 cache 路徑，重新執行偵測
venv/bin/python src/evaluate_samples.py --cache scratch/sample_detections_fresh.json --output scratch/samples_fresh

venv/bin/python src/test_video.py --video data/raw/wash_7steps_yt.mov --ori 1.5 --max-frames 0 --output data/processed/wash_7steps_review_fixed.mp4 --trace docs/evaluation/zoomed_after.jsonl
```

更換影片或偵測器後請使用新快取。舊快取只適用本次固定輸入。
