# 取消雙手同時偵測限制：修改與測試

> 最新的掌心優先調整及測試，請見 [掌心優先報告](wash_7steps_palm_priority_report.md)。

日期：2026-09-29。本次依使用者要求，取代上一版「雙手同時 observed 才能計時」限制。

## 現行行為

- 只要任一隻手是當前真實觀測，就可以獨立建立動作及累積進度，不需要曾經偵測到雙手。
- 恢復內、外、夾、弓、大、立、腕的單手形態規則。依手指彎曲、拇指角度、指尖散開及拇指尖至腕距離分類。
- 單手時以掌長正規化後的關節形變速度（除以 dt）驗證動態；雙手連續可見時使用相對移動速度。單手規則原有速度條件也轉成以 30 FPS 等效值比較，避免直接隨 FPS 漂移。
- 不再使用 `both_observed` 作為計時必要條件，也不要求上一幀為雙手。它只決定採用哪種動態特徵。
- 保留當前分類和平滑分類一致、分數 ≥0.45、類間差 ≥0.12、速度 0.15–8.0、最近 0.5 秒內至少 0.20 秒支持證據的檢查。
- held 座標不冒充新觀測。只有 held、沒有真實手時不計時；有一隻真實手加一隻 held 時，真實手可透過單手路徑計時。
- 靜止單手、重偵測首幀、長時間中斷、證據不一致仍暫停計時。共同座標修正、進度不干預分類、禁止 85% 提前完成仍保留。

單手規則是姿勢推測，無法保證被遮擋的接觸位置正確，因此取消限制後仍需面對誤判；本次沒有把完成數當成準確率。
